    Why combine metrics

    Any single metric can move for innocent reasons. Learning changes outputs, and memory growth shifts diversity. Collapse has a shape: memories bunch together while the agent grows more sure of itself. REGRESS alarms on that shape, or on damage in two independent places, so it can fire while accuracy still looks fine.

    Why compare with cycle 0

    A sourdough starter that sours a little each day never tastes different from yesterday. It only tastes different from day one. Every gauge measures distance from the baseline, so slow decay accumulates instead of hiding inside day-to-day noise.

    Default vs calibrated

    The default tolerances are generic guesses. Calibrated tolerances are fitted to healthy runs of this agent (seeds not shown here), so they know how much this agent normally wobbles. Switch the thresholds control and compare how early each one fires.

    monitor = RegressionMonitor(ProbeSuite(probes, holdout_fraction=0.25))
for cycle in range(n):
    report = monitor.evaluate(agent, cycle)
    if report.alarmed:
        print(report.reason)
    agent.consolidate()
monitor.save("history.json")   # then: regress report history.json --html report.html
